# How to use
Run pswds.py or v1.0.exe
On startup it will generate a key and tell you to enter a PIN. It can be any ASCII string, but make sure its memorable.
```
Generating key.dll
Set PIN (Permanant) If entered incorrectly too many times all passwords are deleted :
```
Then it will tell you to enter it again.
```
Enter PIN: 
```
Would you like to add a password?
```
Add password? (y/n)
```
#### Y
```
Password
```
Now you enter your password.
```
Notes
```
Now any notes you would like to add.
```
Password Name (File Name)
```
The file name for the file it is stored in.

#### N
